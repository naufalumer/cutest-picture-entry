# Cutest picture entry

A front close-up of a Japanese girl, 18, with half black half pink hair tied in a ponytail, pink eyes, a gold dangling earring, and a pink swirl lollipop in her mouth. She wears a pink and black streetwear hoodie. No sunglasses, no tattoo. Drawn in a Makoto Shinkai-like anime style.

`main.py` places `cutest.jpg` at `/output/entry.png` with a plain byte copy, so every run writes the same bytes.
